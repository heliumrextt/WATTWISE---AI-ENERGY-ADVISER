How WattWise works

1. Input. Appliance list and last 12 months of bills.

2. Analyse. Calculates units and cost per appliance and ranks them.

3. Forecast. Linear regression with seasonal terms (trend + sin/cos of month) predicts upcoming units.

4. Advise. Rules turn the numbers into plain-language tips in English or Hindi. In the full project an LLM can phrase these tips from the same numbers.

All values are simulated demo data based on typical Indian household appliances. CO₂ uses an approximate grid factor of 0.71 kg per unit. Replace the demo data with real readings to use the tool.
